# Code of Conduct

Breakproof is a tooling project: be direct, be honest, stay on the code.

1. **No personal attacks.** Criticize routes, regexes, and verdicts — never people.
2. **No spam.** One issue per problem, one pattern per framework request.
3. **Respect maintainers' no.** A declined PR is a decision, not an insult.
4. **Report harassment** to team@auditscan.sh. We act within 72 hours.

Enforcement: warning, then temporary ban, then permanent ban for repeat or
egregious violations. This is adapted from the Contributor Covenant's spirit
without its bureaucracy — small project, small rules, evenly applied.
