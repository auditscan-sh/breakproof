# Security Policy

## Reporting

Don't open a public issue. Email **team@auditscan.sh** with the details.
We respond within 72 hours and credit reporters on request.

## Scope notes

Breakproof is read-only and offline: it never executes scanned code, makes
no network calls, and writes only files you name explicitly. Most reports
here will concern extractor accuracy (missed routes), which we treat as
correctness bugs — file those as public framework requests instead.
